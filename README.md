# Ignition Sequence · 발사 시뮬레이터

브라우저에서 바로 실행되는 3D 로켓 발사 시뮬레이터입니다. 플로리다 케네디 우주센터 39A 발사장에서 로켓을 쏘아 올려 위성을 궤도에 올리거나, 유인 우주선으로 달에 착륙한 뒤 지구로 귀환합니다.

`index.html` 파일 하나로 동작하며 별도 빌드가 필요 없습니다. 브라우저로 열기만 하면 됩니다. (three.js와 웹 폰트는 CDN에서 불러옵니다.)

## 임무 모드

- **무인 · 위성** — 3단 도달 → 페어링 분리(55 km) → 3단 엔진 정지 → 고도 100 km 이상에서 위성 분리
- **유인 · 달 착륙** — 발사 → 탈출탑 분리 → 3단 엔진 정지 → 착륙선 분리 → 달 착륙(6 m/s 이하, 기울기 25° 이내) → 대기권 재진입 → 낙하산 → 연착륙 또는 대서양 착수

## 기체 디자인

| 디자인 | 특징 |
|---|---|
| 누리호 (KSLV-II) | 75톤 엔진 4기 클러스터, 태극기·"대한민국" 표기 |
| 스타웰 | 균형형 기본 기체 |
| 새턴 V | 흑백 롤 패턴, 긴 연소 |
| 헤비 | 사이드 부스터 2기, 최대 추력 |
| 소유즈 | 부스터 4기, 가볍고 민첩 |

## 조작

| 키 | 동작 |
|---|---|
| `Space` | 점화 (10초 카운트다운) |
| `W` / `S` | 추력 올리기 / 내리기 (엔진 정지 중 `W`는 재점화) |
| `A` / `D` | 자세 제어(RCS) |
| `B` | 역추진 자세 자동 유지 |
| `X` | 단 분리 |
| `C` | 엔진 정지 / 재점화 |
| `V` | 임무 동작 (위성 분리 · 착륙선 분리 · 귀환 출발 · 낙하산 펴기/접기) |
| `R` | 리셋 |
| 마우스 휠 | 확대 / 축소 |

## 시뮬레이션 요소

- 고도에 따른 중력·공기 밀도, 항력, 측풍과 돌풍
- 관성이 있는 자세 제어, 대기 중 공력 안정(웨더콕킹)
- 마하수·동압 표시, 최대 동압 구간에서 받음각이 크면 구조 하중 초과로 기체 분해
- 재진입 열차폐 소모와 플라즈마 통신 두절, 수동 낙하산(고도 8 km · 300 m/s 이하에서 전개)
- 착지 직전 역추진 연착륙 엔진(육지), 대서양 착수(바다)
- 영어 관제 음성(퀸다 톤 포함), 합성 엔진 효과음
- 4K 렌더링과 그림자(표준 화질로 전환 가능)
- 플로리다 우주 해안 지형: 대서양, 케이프 커내버럴, 모스키토 석호, 인디언강, 39A·39B 발사장, 조립동, 타이터스빌 시가지

## 참고

지형과 시설 배치는 실제 케네디 우주센터를 참고했지만 게임 화면에 잘 보이도록 일부 위치를 조정했습니다. 물리 수치도 플레이하기 좋게 단순화했습니다.
